# 內科交通政策實驗室

台北黑客松 2026 參賽作品。以內湖科技園區平日晨峰車流為核心：用熱力儀表板呈現每 15 分鐘流入內湖的車流熱點，再延伸到錯峰情境、民眾錯峰建議，以及給市府與企業協商用的數據依據。

> 目前為賽前準備階段。主辦方 10/24 才公布題目，現有內容以能套用到多數題目的通用設計與規劃為主。

## 產品結構

每個題目都依同一個結構設計：

1. **熱力圖**：問題在哪裡、什麼時候發生。
2. **幫你決定**：給民眾一個具體建議（幾點經過塞車路段、走哪條路、停哪裡），建議當天固定，不會一直往後延。
3. **如果大家都這樣**：處理所有人都照建議做時的集體效應，例如時段認領名額、分散推薦、容量檢核。
4. **城市行動**：把民眾的認領與回報彙總成給市府的證據，附負責局處；並提供給市府與企業的協商一頁紙。

## 資料標示

畫面上的每張圖、每個數字都標示以下其中一類：

- 真實觀測
- 程式計算
- 情境假設
- AI 生成

模擬資料一律加斜線紋路。目前設計範本中的數字**全部為模擬資料**。
