# 首頁改稿（依視覺提案第一張）

視覺提案第一張（3D 玩具車、可愛風）的修改版。`index.html` 直接用瀏覽器打開就能看，不需要畫布的執行環境；`preview.png` 是 390×844（iPhone 14）的第一屏截圖。

卡片上的數字取自 [`data/mock/t4-morning.json`](../../data/mock/t4-morning.json)：堤頂大道北向、08:30 前要到公司的建議。**全部是模擬資料。**

## 保留原稿的部分

- 3D 玩具車插畫：`hero-toy-road.webp`（27 KB）直接從設計稿裁下，去掉原本畫在圖上的字，副標改用網頁文字疊上去。
- 字標字型改用 Google Fonts 的 Grandstander 800，是最接近原稿的免費字型。
- 橘色＋青色的配色、「把塞車捲起來」、按鈕「點我⋯！」的語氣、置中的大字主文案。

## 改了什麼、為什麼

| 原稿 | 改成 | 原因 |
| --- | --- | --- |
| 主文案白字放在桃橘底上（對比約 1.8:1） | 深咖啡字 `#5A2410`（6.7:1） | 原本在手機、戶外幾乎看不清楚；一般文字要 4.5:1 |
| 按鈕白字放在青色上（約 1.9:1） | 青色不變，字改深藍 `#0B3A4A`（6.3:1），加上和插畫一樣的「膨膨」立體感 | 同上 |
| 副標橘字（約 2.4:1）、標題（約 2.6:1） | 副標 `#A63C16`（5.3:1）、標題 `#D9522A`（3.6:1，大字標準 3:1） | 同上 |
| 「幫你找出更好的出門時間」 | 「告訴我們你從哪裡來、幾點要到，幫你挑一個比較不塞的時段。」 | [`PRODUCT.md`](../../PRODUCT.md)：建議的是經過入口的時間，不是出門時間，因為我們不知道使用者從哪裡出發 |
| 「幫你找到不塞的那15分鐘」 | 「每 15 分鐘一格，挑出比較順的那格」 | 原本容易讀成「幫你省 15 分鐘」或「保證不塞」，實際是「路上少 3–4 分」的區間 |
| 「點我準備出門！」 | 「點我挑時段！」，下面一行「約 30 秒・不用註冊・設定只存在你的手機」 | 保留原本的語氣；寫出要花多久、不收個資，降低點下去的猶豫 |
| 無 | 結果預覽卡：建議時段、少幾分、早到幾分，與 07:00–09:30 每 15 分鐘的車速格子 | 讓人一眼看到會得到什麼（`ROLES.md` 設計完成標準：首頁 30 秒看懂） |
| 按鈕在頁面最下面 | 按鈕固定在畫面底部 | LINE 內建瀏覽器的可視高度較矮，原本的位置會被擠出第一屏 |
| 沒有 logo | 左上加 logo：一條被捲起來的路 | 網站圖示、分享卡角落、LINE 預覽都需要。目前是暫代版本 |
| 選單圖示淺橘 | `#C2481E`（4.9:1） | 圖示至少要 3:1 |
| 無 | 題目副標「內科晨峰・平日 07:00–09:30」 | `ROLES.md`：總名稱加題目副標，換題時只換這一行 |
| 無 | 「市府與企業：看熱力圖與協商一頁紙 →」 | 首頁也要能通往給市府與企業的頁面 |
| 無 | 卡片角落「含模擬資料」、格子斜線紋路、頁尾說明 | 資料標示規則 |

## 色彩分工

- **橘色代表塞車：** 只用在插畫、字標與 logo。字標的 `#D9522A` 和壅塞色階的 `#F2804A` 很接近，所以資料畫面上的按鈕、標籤不用橘色。
- **青色代表行動：** 按鈕、建議時段。和錯峰情境色階的「藍＝改善」一致。
- 資料畫面（熱力圖、錯峰情境、協商一頁紙）照舊使用 [`Tokens.dc.html`](../heatmap-canvas/Tokens.dc.html)。

## 換題時要改

1. 題目副標與 `<title>`、`<meta>` 說明。
2. 插畫上的副標（目前不提地名，多半不用改）。
3. 預覽卡：時間、地點、分鐘數取自 `decide.plans`，格子顏色取自 `heatmap` 該列。
4. 插畫換成該題的版本。
