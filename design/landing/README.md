# 首頁改稿（依視覺提案第二張）

視覺提案第二張（晨光照片、襯線字標）的修改版。`index.html` 直接用瀏覽器打開就能看，不需要畫布的執行環境；`preview.png` 是 390×844（iPhone 14）的第一屏截圖。

卡片上的數字取自 [`data/mock/t4-morning.json`](../../data/mock/t4-morning.json)：堤頂大道北向、08:30 前要到公司的建議。**全部是模擬資料。**

## 保留原稿的部分

襯線字標 Traffic／Gem、銅色的 Gem、標題下的短橫線、左上 logo、右上弧線、晨光色調、沉穩的語氣。

## 改了什麼、為什麼

| 原稿 | 改成 | 原因 |
| --- | --- | --- |
| 「幫你找出更好的出門時間」 | 「告訴我們你從哪裡來、幾點要到，幫你挑一個比較不塞的時段。」 | [`PRODUCT.md`](../../PRODUCT.md)：建議的是經過入口的時間，不是出門時間，因為我們不知道使用者從哪裡出發 |
| 「找到不塞的那15分鐘」＋「15 min」圓盤 | 「每 15 分鐘一格，找出⋯比較順的那一格」＋結果預覽卡 | 原本容易讀成「幫你省 15 分鐘」，實際是「路上少 3–4 分」的區間。預覽卡讓人一眼看到會得到什麼（`ROLES.md` 設計完成標準：首頁 30 秒看懂） |
| 城市晨光實景照片 | 插畫：晨光、山、天際線、聯外橋樑 | 照片如果是 AI 生成，就是一張不存在的台北，和「沒有資料就留白」的原則衝突；城市晨光照也很像競選與建案廣告。要用照片，請換成實拍的堤頂大道或成美橋，並標出拍攝地點 |
| 銅色按鈕「點我準備出門！」 | 深藍按鈕「開始設定，約 30 秒」，下面一行「不用註冊・設定只存在你的手機」 | 銅色和錯峰情境色階的「明顯惡化」`#B4501A` 幾乎同色；深藍是 tokens 主色。寫出要花多久、不收個資，降低點下去的猶豫 |
| 按鈕在頁面最下面 | 按鈕固定在畫面底部 | LINE 內建瀏覽器的可視高度較矮，原本的位置會被擠出第一屏 |
| 灰色副標（對比約 3.3:1） | `#4A4F56`（6.6:1 以上） | 一般文字要 4.5:1 |
| 無 | 題目副標「內科晨峰・平日 07:00–09:30」 | `ROLES.md`：總名稱加題目副標，換題時只換這一行 |
| 無 | 「市府與企業：看熱力圖與協商一頁紙 →」 | 首頁也要能通往給市府與企業的頁面 |
| 無 | 卡片角落「含模擬資料」、格子斜線紋路、頁尾說明 | 資料標示規則 |

## 色彩

沿用 [`Tokens.dc.html`](../heatmap-canvas/Tokens.dc.html)：底色 `#F5F4EF`、主色 `#1F4E79`、壅塞色階。新增的品牌色只有銅色，**只用在字標、logo 與裝飾，不用在按鈕和資料**，避免和壅塞色階混淆。

| 用途 | 前景 / 背景 | 對比 |
| --- | --- | --- |
| 字標 Gem（大字） | `#B5652F` / 天空 `#FBF6EE` | 4.0:1（大字標準 3:1） |
| 題目副標（小字） | `#9A4F1F` / `#FBF6EE` | 5.6:1 |
| 副標、說明 | `#4A4F56` / `#F6E4CF` | 6.6:1 |
| 主要按鈕 | 白 / `#1F4E79` | 8.7:1 |

## 換題時要改

1. 題目副標與 `<title>`、`<meta>` 說明。
2. 副標裡的入口名稱（堤頂大道、成美橋）。
3. 預覽卡：時間、地點、分鐘數取自 `decide.plans`，格子顏色取自 `heatmap` 該列。
4. 插畫裡的車：機車、捷運、停車題目換成對應的圖形，色調不變。
